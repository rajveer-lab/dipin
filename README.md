# Dip In

A live-match companion for cricket fans who can't watch every ball. It tells you whether the match is worth watching right now, pings you only when it gets tense, and catches you up on what you missed when you come back.

## What it does

- **Should I watch?** A tension meter from 0 to 100, built from how close the result is, how late it is in the match and how recently a wicket fell. The top of the screen shifts from cool blue to hot red with it.
- **Pings that are worth it.** Alerts for tense finishes, big wickets and last overs, nothing else. A lock-screen view shows what a fan sees while they're away.
- **Catch me up.** A summary of everything since you last looked, innings break included.
- **Ask.** Questions about the match ("Can CSK still win?", "Who bowls the last over?"), answered from the live scorecard.

Three matches are included: a made-up demo match with a one-run finish, and two real finals replayed ball by ball from Cricsheet data, the IPL 2019 Final (MI v CSK) and the 2024 men's T20 World Cup Final (India v South Africa).

## Run it

Needs Node.js. There are no packages to install.

```bash
node serve.js
```

Then open http://localhost:5317.

```bash
node build.js
```

This writes `dist/index.html`, one self-contained file for any static host, and `dist/dipin.html`, the same page without the document skeleton.

## How it works

| File | What it does |
|---|---|
| `engine.js` | The match engine. Takes a feed of balls and works out the score, win chances, tension and alerts after each one. Also simulates the demo match through the same feed. |
| `adapters/cricsheet.js` | Turns a Cricsheet match file into that feed, and works out which competition a match belongs to. |
| `data/levels.js` | How high each of 18 T20 competitions scores, season by season, and how much easier or harder chasing is there. Generated by `tools/make-levels.js`. |
| `data/replays.js` | The bundled replays, generated by `tools/make-replays.js` from `data/cricsheet/`. |
| `ai.js` | Talks to a language model for Catch me up and Ask. |
| `app.js`, `index.html`, `styles.css` | The app itself. |

The engine has no idea whether a ball is simulated, replayed or live. A live source only needs to send balls in the format described at the top of `engine.js`, plus two scoreboard messages no ball carries:
- a rain limit with a revised target;
- the result, when the engine can't work it out itself (DLS, a super over, no result).

### Tested on 12,163 real matches

`tools/replay-all.js` feeds every T20 in Cricsheet's archives through the engine one ball at a time, as a live feed would. That covers the IPL, 11 other leagues and all T20 internationals, men's and women's. It then checks every innings total, wicket count, crease change and result against Cricsheet.

| Kind of match | Matches | Fully right |
|---|---|---|
| Normal | 11,125 | 100% |
| Rain-shortened | 681 | 100% |
| No result | 235 | 100% |
| Tied, including super overs | 118 | 100% |
| Awarded or forfeited | 4 | 100% |

The engine also copes with:
- miscounted 7-ball overs;
- penalty runs;
- two dismissals on one ball;
- two sides with the same initials.

7 normal matches are left out because Cricsheet's own balls don't add up to its result.

### Win model

The win chances come from a model fitted on 1,195 IPL matches from 2008 to 2026:

1. It estimates the runs still to come from balls and wickets left, using the same idea as DLS, scaled to the competition's typical first-innings score.
2. It turns that into a win chance, tuned against how real chases actually finished.
3. It shifts that by the competition's chasing edge. Chasing is harder than the runs suggest in lower-scoring women's cricket, and easier in the PSL.

On IPL seasons it never saw (2024 to 2026) it cut the error in chase predictions (log loss) from 1.01 to 0.37.

`tools/accuracy.js` scores it in all 18 competitions, using only what a live app would know: the previous season's level and the edge learnt from earlier seasons. When it says 30%, chasers win about 30%. Its chance is off by **0.9 points** on average, against 17 points if every competition were scored like the IPL.

| Pings, across 11,381 matches | Close finishes pinged | First ping before the end (median) | One-sided games pinged |
|---|---|---|---|
| With `data/levels.js` | 89% | 35 balls | 6% |
| Without it | 82% | 25 balls | 14% |

A competition missing from the table gets the usual level for men's (177) or women's (155) T20. Rerun `tools/make-levels.js` after each season.

### AI

Catch me up and Ask use a language model when one is reachable:

- the `sample` capability, when the page runs as a claude.ai artifact;
- otherwise a `POST api/ai` route on the same host. That route is not part of this repo yet.

Without either, a built-in narrator answers from the same match facts, so every feature still works offline.

## Checks

```bash
node tools/check-engine.js
node tools/check-replay.js
```

- `check-engine` replays the demo match against a recorded baseline and confirms that a ball-by-ball feed rebuilds the same match.
- `check-replay` compares the replayed finals with Cricsheet's own figures for every batter, bowler and ball.

## Tools

These need match archives from [cricsheet.org/downloads](https://cricsheet.org/downloads/) (for example `ipl_json.zip`, `bbl_json.zip` and `t20s_json.zip`), each unzipped into its own folder:

```bash
node tools/replay-all.js <folder> [<folder> ...]
node tools/accuracy.js <folder> [<folder> ...] [--edge]
node tools/alert-stats.js <folder> [<folder> ...]
node tools/make-levels.js <folder> [<folder> ...]
node tools/calibrate.js <ipl folder> [--final]
```

- `replay-all` replays every match as a live feed and checks the engine against Cricsheet.
- `accuracy` scores the win chances in each competition.
- `alert-stats` measures how well the pings separate close finishes from one-sided games.
- `make-levels` rebuilds `data/levels.js`.
- `calibrate` refits the win model on IPL data and tests it on held-out seasons.

## Data

Ball-by-ball data comes from [Cricsheet](https://cricsheet.org) under the [Open Data Commons Attribution License](https://opendatacommons.org/licenses/by/1-0/). The files in `data/cricsheet/` are original Cricsheet files with their data unchanged. The teams in the demo match are made up.
